Five free providers, five different rate limits. Each agent role gets an ordered fallback chain;
a 429 or timeout puts that model on cooldown and the call moves down the chain. In practice the
free quotas add up instead of blocking each other.

```python
ROLES = {
  "supervisor": ["gemini/gemini-2.5-flash", "groq/llama-3.3-70b", "cerebras/llama-3.3-70b"],
  "writer":     ["openrouter/deepseek-v3", "mistral/mistral-large", "gemini/gemini-2.5-flash"],
}
```
