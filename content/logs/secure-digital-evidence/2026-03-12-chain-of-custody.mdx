challenge: "The custody chain hashed only the link between entries. Editing a note or a timestamp in the database still left the chain \"valid\"."

---

First version linked each custody entry to the previous one by hash — but only the link. Editing
a note or a timestamp in the database left the chain "valid". Now every block's hash covers its
index, the previous hash, the action, custodian, notes, timestamp **and** the file's SHA-256, and
verification recomputes every block from scratch.

```ts
const payload = `${index}|${prevHash}|${action}|${custodian}|${notes}|${timestamp}|${fileSha256}`;
const hash = createHash("sha256").update(payload).digest("hex");
```

Side effect: a broken chain now tells you *which* block changed, not just that something did.
